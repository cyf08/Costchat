问题: 我名下哪些云账户今年六月的费用波动最大 top5 ？
问题ID: 44-1
描述: 通过费用的不稳定性（标准差）来识别那些可能存在风险的账户。
预期SQL: SELECT account_id, STDDEV(daily_cost) as cost_stddev FROM (SELECT account_id, DATE(usage_end_time) as day, SUM(real_billing_cost) as daily_cost   FROM mcmp_cost_tst.billing_item_monthly   WHERE tenant_id = 88  AND month = '202506'   GROUP BY account_id, day) AS subquery GROUP BY account_id ORDER BY cost_stddev DESC LIMIT 5;
