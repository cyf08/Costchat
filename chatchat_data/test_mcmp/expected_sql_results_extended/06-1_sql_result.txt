问题: 我今年每个季度的总花费是多少？
问题ID: 06-1
描述: 按季度汇总成本，适用于季度性的财务报告。
预期SQL: SELECT CEIL(CAST(SUBSTRING(CAST(month AS CHAR), 5, 2) AS INT) / 3) AS quarter, SUM(real_billing_cost)  AS quarterly_cost FROM mcmp_cost_tst.billing_item_monthly WHERE tenant_id = 88 AND SUBSTRING(CAST(month AS CHAR), 1, 4) = YEAR(NOW()) GROUP BY quarter ORDER BY quarter;
