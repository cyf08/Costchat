问题: 统计六月孤立磁盘卷的浪费成本
问题ID: 37-3
描述: 此查询专门针对最常见的云浪费类型之一：未挂载的磁盘卷。通过筛选出那些没有root_resource_id（通常是虚拟机ID）的磁盘卷计费项，可以非常精确地定位这些“僵尸”资源，它们是最高优先级的清理和降本对象。
预期SQL: SELECT resource_id, resource_name, SUM(usage_cost) AS orphaned_disk_cost FROM mcmp_cost_tst.billing_item_monthly WHERE tenant_id = 88 AND month = '202506' AND record_type = 'Usage' AND (product_code = 'EC2' AND usage_type LIKE '%EBS:Volume%') AND (root_resource_id IS NULL OR root_resource_id = '') GROUP BY resource_id, resource_name ORDER BY orphaned_disk_cost DESC;
